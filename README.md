# 🤖 Intelligent Excuse Generator

An AI-powered web application that generates realistic excuses and supporting fake documents (like doctor's notes) for various life scenarios.

## 🚀 Live Preview

Run it in Google Colab and access the site through ngrok.

## 📦 Features

- ✅ Excuse generator for work, school, social, and family situations
- ✅ Customizable tone (emotional, professional, neutral)
- ✅ PDF doctor's note generator
- ✅ Fake chat screenshot for added believability
- ✅ Simple Flask-powered web UI
